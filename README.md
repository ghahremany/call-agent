# AgentCall — منشی صوتی

منشی تلفنی هوشمند فارسی، در PHP خالص، برای هاست اشتراکی (InfinityFree).
ساخته‌شده از روی یک ورک‌فلوی n8n، ولی بدون n8n و بدون Node.

```
مرورگر (ویجت تلفن یا call.html)
   │  میکروفون → ضبط → POST
   ▼
api.php
   ├─ event=start ────────────────► پیام خوش‌آمد (از کش، فوری)
   └─ audio ─► تشخیص گفتار (ElevenLabs Scribe v2)
                  │
            Fast Path Router ──── بدون AI: تایید / رد / خداحافظی / نام و شماره
                  │
            (اگر لازم بود) مدل زبانی ─► JSON: intent + name + phone + slot
                  │
            ماشین حالت ─► انبار وقت‌ها (فایل / MySQL / گوگل‌شیت)
                  │
            ElevenLabs TTS v3 ─► audio/mpeg + هدر X-Call-Ended
```

## امکانات

- **گفتگوی نوبتی فارسی** — تشخیص گفتار، فهم، و گفتار؛ همه روی هاست اشتراکی.
- **Fast Path Router** — تایید/رد/خداحافظی/نام و شماره بدون مدل زبانی حل می‌شوند
  (سریع‌تر و ارزان‌تر). در تست واقعی: **۱ میلی‌ثانیه**.
- **ماشین حالت** — `idle` → `awaiting_confirm` → `awaiting_info` → `ended`.
- **پنل مدیریت** — ورود سه‌مرحله‌ای (نام کاربری + رمز + رمز یکبارمصرف گوگل)،
  کپچا بعد از خطاهای پی‌درپی، ۱۰ تب.
- **تقویم شمسی** — نوبت هر روز روی تقویم؛ تبدیل شمسی↔میلادی بدون وابستگی.
- **ربات‌ها** — چند درگاه مدل زبانی با اولویت و failover خودکار.
- **دانشنامه** — متن «منشی چطور حرف بزند» با تاریخچهٔ نسخه‌ها.
- **پروندهٔ مشتریان** + خروجی CSV.
- **ویجت تلفن** — یک خط اسکریپت؛ دکمه کنار لوگوی چت می‌نشیند و **مثل تماس
  ورودی می‌لرزد**. با کلیک، صفحهٔ تماس **تمام‌صفحه** باز می‌شود (سبک آیفون با
  Dynamic Island)، چند لحظه بوق می‌خورد و بعد منشی جواب می‌دهد.
- **صفحه‌کلید شماره** — وقتی منشی شماره می‌خواهد، مرورگر یک صفحه‌کلید عددی
  باز می‌کند. گفتن ۱۱ رقم پشت سر هم برای تشخیص گفتار سخت است، پس کاربر می‌تواند
  شماره را تایپ کند. (دکمهٔ «ترجیح می‌دهم بگویم» هم هست.)
- **بسته‌شدن خودکار** — با زدن دکمهٔ پایان، صفحه بسته می‌شود؛ اگر منشی خودش
  خداحافظی کند، بعد از شنیدن خداحافظی بسته می‌شود.
- **اطلاع‌رسانی فوری رزرو** به بله/تلگرام.
- **پشتیبان صدای مرورگر** — اگر سرویس گفتار کار نکند، مرورگر متن را می‌خواند.

## راه‌اندازی

### ۱) کلیدها
`voice-secrets.example.php` را به `voice-secrets.php` کپی کن:

```php
return [
    'el_key'   => 'sk_...',    // ElevenLabs
    'groq_key' => 'gsk_...',   // Groq
];
```

### ۲) انبار
```php
'store_driver' => 'file',   // file | mysql | sheets
```
`file` بدون هیچ تنظیمی کار می‌کند. برای `mysql` اطلاعات دیتابیس را در
`voice-config.php` بگذار — جدول‌ها خودکار ساخته می‌شوند.

### ۳) پنل
`panel.php` را باز کن. صفحهٔ راه‌اندازی می‌آید: نام کاربری و رمز را بساز،
و کلید رمز یکبارمصرف را در Google Authenticator ثبت کن
(**فقط یک بار نشان داده می‌شود**).

### ۴) وقت‌ها
پنل → تب «وقت‌ها» → روزهای کاری و ساعت‌ها را بده → «همین حالا بساز».
**تا وقتی وقت آزاد نباشد، منشی نمی‌تواند نوبت بدهد.**

### ۵) ویجت روی سایت
قبل از `</body>`:
```html
<script src="https://<دامنه>/voice/voice-widget.js?v=3"
        data-kb="personal" data-title="تماس صوتی" defer></script>
```
- `data-kb` — کدام دانشنامه: `personal` · `ngy` · `clinic`
- `data-title` — نامی که در صفحهٔ تماس نشان داده می‌شود

⚠️ هر بار فایل ویجت را عوض کردی، `?v=` را بالا ببر — روی این هاست JS یک ماه کش می‌شود.

## نکته‌های مهم

**صفحهٔ تماس باید هم‌دامنهٔ `api.php` باشد.** InfinityFree یک چالش ضدربات
(aes.js) دارد که درخواست cross-origin را می‌گیرد.

**فارسی روی ElevenLabs فقط با `eleven_v3` و `eleven_v4`.** مدل‌های سریع
(`eleven_flash_v2_5`، `eleven_multilingual_v2`) فارسی را در فهرست زبان‌هایشان
ندارند. برای Scribe هم `language_code` باید `fas` باشد (نه `fa`).

**اشتراک رایگان ElevenLabs مجوز تجاری ندارد** و ۱۰٬۰۰۰ کاراکتر در ماه است.

**کلیدها هرگز در `call.html` یا `voice-widget.js`.** فقط در `voice-secrets.php`
که از وب مسدود است (دو لایه: `.htaccess` + نگهبان `VOICE_APP`).
